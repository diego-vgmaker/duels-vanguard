# duels.vanguard

Free, unofficial, automated **Cardfight!! Vanguard** simulator for the Standard format (overDress / D-series onward).

**Play:** https://diego-vgmaker.github.io/duels-vanguard/

- Quick matches vs bot, deck builder, card pool and local ranking
- Card abilities programmed in the rules engine
- Single-file static site (`index.html`), hosted on GitHub Pages
- Optional player accounts (email/password or Google) and a public **Meta** page with the most played nations, vanguards and cards, backed by Supabase. Decks stay in the player's browser. Setup: [`docs/SETUP-ONLINE.md`](docs/SETUP-ONLINE.md), schema: [`supabase/schema.sql`](supabase/schema.sql)
